# Security Policy

## Supported Versions

The program supports Chromium 74+. We could allow 4.0 with some minor bugs, but under 3.0 has the incorrect software used to run it.

| Version | Supported          |
| ------- | ------------------ |
| 4.0+  | :white_check_mark: |
| Below 3.0   | :x:                |
